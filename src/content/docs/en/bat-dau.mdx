## What you need to put in: money · time · people

### Money — everything beyond the box

The box and package you bought are **not the whole picture**. This table gathers every remaining item so you can line it up before the box arrives and never get stuck halfway.

| Item | Required? | Cost | Where |
| --- | --- | --- | --- |
| **Control PC** (laptop or desktop) | Required | Use what you have | On hand |
| **Wired network** + 1 free port on the modem | Required | 0 | On hand |
| **Dedicated 3-prong outlet**, not shared with AC or washing machine | Required | Small, if you lack one | Electrical store |
| **Social accounts** — 5 to trial, then up to 20 | Required | See "to fill in" box below | Third party — pick a reputable source |
| **Proxies** — 5 to trial, then up to 20 (one per phone) | Required | See "to fill in" box below | Third party — pick a reputable source |
| **vilao.ai API key** (for automated commenting) | Only if you use automated comments | ~50,000 VND (~2% fee) | [vilao.ai/console](https://vilao.ai/console) |
| **UPS, 1,000VA or more** | Recommended — avoids a crash on power loss | See "to fill in" box below | Electrical store |
| **Cat6 LAN cable** | Only with a mini PC | Small | Computer store |
| **USB-to-LAN / Type-C-to-LAN adapter** | Only if your laptop has no Ethernet port | About 100,000–200,000 VND | Computer store |
| **A phone to film the unboxing** | Required — it is your warranty proof | 0 | On hand |

:::tip[Save money]
Buy only **5 accounts + 5 proxies** to trial first. Scale to 20 once it runs well. Do not buy 20 up front.
:::

### People — who does what

One person can do everything. If your business has two people, split it like this:

* **Business owner** — decides where to buy accounts/proxies, picks the platform and niche (Day 4–5), reads the *Risks* section below, keeps the unboxing video.
* **Operator** — runs the 5-day roadmap, checks the system each morning, messages support with the template when stuck.

## Risks to know before you start

Said plainly, so nothing surprises you. Every risk has a mitigation, and the docs point to the right place.

* **Accounts can get banned** — most often when several phones share one proxy, or Day 2 is set up wrong. *Mitigate:* one proxy per phone, follow Day 2 in order, trial 5 before scaling to 20.
* **Numbers not growing in the first 2–4 weeks is normal** — accounts need time to "come alive". *Mitigate:* stop changing settings; pick the right niche on Day 4–5.
* **Heat and power** — a box in a closed cabinet throttles itself; sharing an outlet with a heavy appliance crashes the system mid-run. *Mitigate:* airy spot, dedicated outlet, a UPS.
* **Installing the wrong app** — links in the old manual lead to a different app. *Mitigate:* use only the official APK folder from Day 2.
* **Hardware warranty** — without an unboxing video it is hard to prove a factory defect. *Mitigate:* film **before breaking the seal**, keep the seal intact.
* **Accounts and proxies are your cost**, bought from third parties — choose reputable sources and start small.

## Questions new customers often ask

**I'm not tech-savvy — can I still use this?**
Yes. The 5-day roadmap is written for complete beginners — one thing a day, no jargon, and a [glossary](/en/thuat-ngu) when you need one.

**What if I get stuck?**
Open [Look up by symptom](/en/tra-cuu-theo-trieu-chung) first. Still stuck? [Message WhatsApp support](/en/lien-he-ho-tro) using the template — send all 5 items and you'll be helped in one reply.

**What is the HDSD?**
It is the full 141-page **User Manual** that ships with the hardware. This site teaches *the order and the why*; the HDSD is the detailed reference. "HDSD p. 30" means open page 30 of that manual.

**Can I run this on a wifi laptop?**
Yes, if you use a **GenRouter H3000**. If you use a **mini PC**, you must connect over **LAN** — a laptop without an Ethernet port needs a USB-to-LAN adapter. See the "How to connect the control PC" table in [Day 0](/en/a2-lo-trinh-mot-tuan/a3-ngay-0-chuan-bi).
