**Layer 4 · Automation**

> **Question of the day:** Can the machine do the work for me?
>
> Today you do not learn a new feature. You simply hand over to the machine the things you did by hand over the past two days.

## What automation is

It is the very same actions you tapped by hand on [Day 1](/en/a2-lo-trinh-mot-tuan/a4-ngay-1-phan-cung) and [Day 2](/en/a2-lo-trinh-mot-tuan/a5-ngay-2-danh-tinh), recorded as a script and run on many phones at once. No coding needed; you just select and click.

| Tool                            | What it does                                                                                                                                                                                                      | When to use it                   |
| ------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------- |
| **Auto Login**                  | Logs in and logs out in bulk instead of typing on each phone by hand                                                                                                                                              | Today                            |
| **Trust** (warming up accounts) | The phone watches videos, scrolls, likes and follows like a real person with clear interests. The goal is for the platform to register this account as belonging to someone with habits, not a brand-new account. | Run for **2–4 weeks**            |
| **Boost** (boosting engagement) | Concentrates engagement on one specific post so the platform distributes it more widely                                                                                                                           | **Only after enough warming up** |

:::danger
Turning on **Boost** on an account that has not been warmed up is the fastest way to lose it, and an account that has once run junk engagement is very hard to recover.
:::

**Download the automation package → Run Auto Login → Turn on Trust to warm up accounts**

## Steps

### Check that the platform app is on the phones

The platform app was installed on [Day 2 · step 3](/en/a2-lo-trinh-mot-tuan/a5-ngay-2-danh-tinh). Install it on any phone that is missing it, following the instructions there — download from the official APK folder, not the links in the User Manual (HDSD).

### Download the automation package for your platform

<figure><img src="/images/sc-store.jpg" alt="Mini-App Store" loading="lazy" /><figcaption>Mini-App Store: pick the automation package for your platform and download it.</figcaption></figure>

Go to the **Store**, find it and download it. A video guide is included — see the [GenFarmer video playlist](https://www.youtube.com/watch?v=dWUFV9oCnL0\&list=PLDKj59ZxjjPzvYAxEBUXjYxkUAG624lBu\&index=10). _HDSD p. 18–20 · 52–55 · 80–83_

### Download the platform's three tools

**Auto Login**, **Trust** and **Boost**. _HDSD p. 21–24 · 56–59 · 84–88_

<figure><img src="/images/13-a6-hop-genfarmer-trust.jpg" alt="GenFarmer Trust box" loading="lazy" /><figcaption>GenFarmer Trust — the account warm-up package. At the end of Day 3 you turn on Trust for the 5 accounts.</figcaption></figure>

### Open the Account Manager screen

This is where you choose which account runs which script. On Day 2 you used this screen to store accounts; today you use it to **give orders**.

### Run Auto Login on exactly the 5 accounts you already have

<figure><img src="/images/sc-automation-tools.jpg" alt="Setup Automation" loading="lazy" /><figcaption>Setup Automation: select exactly the 5 accounts you already have, then run Auto Login.</figcaption></figure>

Do not scale up yet.

### Turn on Trust for those 5 accounts

Let it run overnight.

### Check the next morning

<figure><img src="/images/sc-schedules.jpg" alt="Schedules screen" loading="lazy" /><figcaption>The Schedules screen: next morning, check that last night's schedules ran to completion.</figcaption></figure>

If all 5 are still alive, buy more to reach 20, then run Auto Login and Trust on all 20 phones.

## Done when

:::tip
**20 phones log in on their own and warm up accounts overnight** without you having to step in.
:::

:::danger
If any account gets banned overnight, **do not scale up**. Go back and check the proxies and the running speed first.
:::

## Three common mistakes

| ✕ | Mistake                                                                           | Consequence                                                                                                                                                                                      |
| - | --------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 1 | Turning on Boost on the first day because you want to see results early           | The most expensive mistake in the whole roadmap                                                                                                                                                  |
| 2 | Running at full capacity on the first run instead of ramping up gradually         | Accounts get banned in bulk                                                                                                                                                                      |
| 3 | Only discovering you have no vilao.ai API key when you reach automatic commenting | You have to stop halfway. This was already part of [Day 0](/en/a2-lo-trinh-mot-tuan/a3-ngay-0-chuan-bi). Note: even with the right API, if the provider's model has an outage, automatic commenting may still be affected |
