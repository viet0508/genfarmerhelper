title: "症状から探す"
description: "2回目以降に読むためのページです。画面に表示されているものから探して、どのレイヤーが壊れているか、どのページを開けばよいかがすぐに分かります。"
---

初めて読むときは、資料を順番に読みます。2回目以降は、画面に表示されているものから探すことになります。この表はその2回目のためのものです。

<figure><img src="/images/15-tra-cuu-giao-dien-phan-mem.jpg" alt="Device 画面" loading="lazy" /><figcaption>ソフトウェアの Device 画面。ここに表示されているものそのままで探します。</figcaption></figure>

| 症状                         | レイヤー         | 開くページ / 対処                                                                                                                                                                                                                                       |
| -------------------------- | ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Scan** を押しても端末が1台も見つからない | 1 · 端末       | _ユーザーマニュアル（HDSD）p.4–8_ — 2つのアドレス範囲と **Active** ボタンを確認します（[A4 · 手順3](/ja/a2-lo-trinh-mot-tuan/a4-ngay-1-phan-cung)）                                                                                                                                   |
| 端末は見つかるが画面が真っ暗             | 1 · 端末       | 準備中 — スクリーンショットを添えて[サポートに連絡](/ja/lien-he-ho-tro)してください                                                                                                                                                                                               |
| 端末は表示されるがネットワークにつながらない     | 2 · ネットワーク   | まずプロキシを確認します。プロキシに問題がなければ、スマートフォンの時刻を確認します（[A4 · 手順3](/ja/a2-lo-trinh-mot-tuan/a4-ngay-1-phan-cung)）。それでも直らなければ、GenRouter の Isolate Mode を確認します（[A5 · 手順2](/ja/a2-lo-trinh-mot-tuan/a5-ngay-2-danh-tinh)） · [プロキシ割り当てのビデオ](https://youtu.be/kGjP-7iqSTI) |
| 多数のアカウントが同時に凍結（BAN）される     | 2 · ネットワーク   | ほぼ常に、複数のアカウントが同じ住所を共有していることが原因です — [A5](/ja/a2-lo-trinh-mot-tuan/a5-ngay-2-danh-tinh)を参照してください。[プロキシの割り当てと Isolate Mode のビデオ](https://youtu.be/kGjP-7iqSTI)も参照してください。詳しい対処手順は準備中です                                                                   |
| ログインできた後に本人確認を求められる        | 3 · アイデンティティ | [A5 の2日目](/ja/a2-lo-trinh-mot-tuan/a5-ngay-2-danh-tinh)を見直します — 拡張せず、アカウントの入手元またはプロキシを変えてやり直します。詳しい手順は準備中です                                                                                                                                          |
| アカウントは生きているが投稿が誰にも見られない    | 3 · アイデンティティ | 多くの場合、2〜4週間の育成が足りていないか、分野の選択を誤っていることが原因です — [A7](/ja/a2-lo-trinh-mot-tuan/a7-ngay-4-5-nen-tang)を参照してください                                                                                                                                             |
| すべて動いているのに数値が伸びない          | 4 · スクリプト    | [プラットフォームの章](/ja/a2-lo-trinh-mot-tuan/a7-ngay-4-5-nen-tang) — 設定の部分                                                                                                                                                                                  |
| インストールしたら別のアプリが入っていた       | 4 · スクリプト    | HDSD 内のリンクからダウンロードしています。[A5 · 手順3](/ja/a2-lo-trinh-mot-tuan/a5-ngay-2-danh-tinh)の公式 APK フォルダーを使ってください                                                                                                                                                |

:::note
どのレイヤーか分からない場合は、[A1 · システムの4つのレイヤー](/ja/a1-bon-lop-he-thong)を読み直してください。サポートが必要なときは、[サポートに連絡する前に](/ja/lien-he-ho-tro)にあるメッセージのテンプレートを使ってください。
:::
