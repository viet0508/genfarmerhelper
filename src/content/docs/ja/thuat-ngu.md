## レイヤー1 · 端末

| 用語                     | 意味                                                                                                            | 登場するページ |
| ---------------------- | ------------------------------------------------------------------------------------------------------------- | ------- |
| **Box / Boxphone**     | GenFarmer から購入する、複数のスマートフォン（通常20台）を収めたハードウェアの筐体です。                                                            | A1, A4  |
| **GenFarmer Software** | PC にインストールして、Box 内のすべての端末を制御するソフトウェアです。[genfarmer.com/download](https://genfarmer.com/download/) からダウンロードします。 | A4      |
| **Control Center**     | ソフトウェア内の手動操作画面です。1台ずつ、または複数の端末を同時に、タップ・入力・操作できます。                                                             | A4      |
| **USBモード**             | Box 1台と GenRouter H3000 を使うときの接続方式です。接続するだけで自動的に認識されます。                                                       | A4      |
| **OTGモード**             | ミニPCを使うときの接続方式です。2つのアドレス範囲を追加し、Active を押してから Scan します。このモードでは、端末はミニPC経由ですでにネットワークにつながっています。                   | A4      |
| **アドレス範囲**             | OTGモードでソフトウェアが端末を見つけられるように、登録が必要な2つのネットワークアドレスの範囲 `192.168.4.1–255` と `192.168.5.1–255` です。                   | A4      |
| **Active / Scan**      | Active：追加したアドレス範囲を有効にします。Scan：端末を検索します。Active の押し忘れは、Scan で端末が見つからない最もよくある原因です。                               | A4      |
| **Device ID**          | 各端末の識別コードで、メイン画面に表示されます。Account Manager でアカウントに端末を割り当てるときに使います。                                               | A5      |
| **APK**                | Android アプリ（TikTok、Facebook など）のインストールファイルです。Install APK ボタンで一括インストールします。                                     | A5      |
| **adb**                | 端末に直接コマンドを送るための Android のコマンドラインツールです。任意で、技術的な知識がある方向けです。                                                     | A4      |

## レイヤー2 · ネットワーク

| 用語                    | 意味                                                                                              | 登場するページ    |
| --------------------- | ----------------------------------------------------------------------------------------------- | ---------- |
| **GenRouter (H3000)** | GenFarmer のルーターで、各端末に専用のインターネット回線を割り当てます。H3000 は Box 1台用です。管理画面は `192.168.5.1:9000` です。         | A1, A4, A5 |
| **ミニPC**              | Box が2台以上のときに H3000 の代わりに使う小型 PC です。Box 内の端末はミニPCのネットワークを使います（OTGモード）。Cat5/Cat6 の LANケーブルが必要です。 | A3, A4     |
| **プロキシ**              | インターネット上でのアカウントの「住所」です。端末ごと／アカウントごとに専用のプロキシが必要で、共有するとアカウントがまとめて凍結（BAN）される原因になります。               | A5         |
| **Isolate Mode**      | GenRouter のモードです。ある端末のプロキシが落ちたとき、本当の住所が露出しないように、その端末のネットワークを即座に遮断します。                           | A5         |

## レイヤー3 · アイデンティティ

| 用語                         | 意味                                                                                        | 登場するページ    |
| -------------------------- | ----------------------------------------------------------------------------------------- | ---------- |
| **アカウント（account）**         | プラットフォーム（TikTok、Facebook など）上のアカウントです。このシステムでは、アカウントは1つのアイデンティティであり、プロキシはそのアイデンティティの住所です。 | A5         |
| **UID \| Password \| 2FA** | アカウントを表に入力するときの既定の形式です。アカウント ID、パスワード、2段階認証コードを縦線で区切ります。Custom から変更できます。                  | A5         |
| **Account Manager**        | アカウントの管理画面です。アカウント表の入力、Device ID の割り当て、そして（3日目以降は）どのアカウントでどのスクリプトを実行するかの選択を行います。          | A5, A6     |
| **本人確認（verification）**     | プラットフォームがアカウントの証明（OTP コード、写真、動画など）を求めることです。いつもより多く本人確認を求められるのは、止めるべきサインです。                | A5, A7     |
| **アカウントの育成／寝かせ**           | 本来の目的に使う前に、アカウントに本物の人間のような習慣を持たせる2〜4週間の期間です。この間に数値の伸びが緩やかなのは正常です。                         | A5, A6, A7 |

## レイヤー4 · 自動化

| 用語                           | 意味                                                                         | 登場するページ |
| ---------------------------- | -------------------------------------------------------------------------- | ------- |
| **スクリプト（script）**            | 端末が自動で実行できるように記録した一連の操作で、複数の端末で同時に実行します。コードを書く必要はありません。                    | A6      |
| **自動化パッケージ（package）/ Store** | プラットフォームごとに用意されたスクリプトのセットで、ソフトウェアの Store からダウンロードします。                      | A1, A6  |
| **Auto Login**               | ログイン／ログアウトを一括で行うツールです。                                                     | A6      |
| **Trust**                    | アカウントを育成するツールです。端末が、はっきりした好みを持つ本物の人間のように視聴・スクロール・いいね・フォローを行います。2〜4週間実行します。 | A6      |
| **Boost**                    | 特定の投稿にエンゲージメントを集中させるツールです。十分に育成した後にのみ使います。                                 | A6      |
| **vilao.ai の API キー**        | 自動コメント機能（AI がコメントを作成）に使うキーです。0日目に準備します。                                    | A3, A6  |
| **コンテンツ分野**                  | アカウントを育成する際のテーマです。選択を誤ると、投稿が届けたい相手に届きません。                                  | A7      |
