## どのくらい時間がかかりますか?

| 段階                                | 時間           | 何をするか                                                              |
| ----------------------------------- | -------------- | ----------------------------------------------------------------------- |
| **オンボーディング (このページ)**   | 5分            | サポート保存、グループ参加、動画視聴、読む準備                          |
| **Day 0 — 準備**                    | 1〜2 時間      | 設置場所、テスト用アカウント/プロキシ購入、開封動画撮影                 |
| **Day 1 → 5 — ロードマップ**        | 5 日           | 1日1問、1日1目標                                                        |
| **アカウントウォームアップ**        | 2〜4 週間      | システムを動かし続ける; アカウントが徐々に「生きる」 — 結果が出始める   |

:::note[メモ]
**システムをマスターすること** と **結果を出すこと** は別です。マスターは5日でできますが、数字が出るにはアカウントを 2〜4 週間ウォームアップする必要があります。先に知っておくとがっかりせずに済みます。
:::

## 新規のお客様からよくある質問

**技術に詳しくないけど使えますか?**
使えます。5日間のロードマップは完全初心者向けに書かれています — 1日1つ、専門用語なし、必要な時のための [用語集](/ja/thuat-ngu) もあります。

**途中で詰まったら?**
まず [症状から検索](/ja/tra-cuu-theo-trieu-chung) を開いてください。それでもダメなら、テンプレートを使って [WhatsApp サポートにメッセージ](/ja/lien-he-ho-tro) — 5項目を送れば一度の返信で解決します。

**他に買うものはありますか?**
box と購入したパッケージに加えて: **アカウント + プロキシ**(サードパーティ)、**vilao.ai の API キー**(約50,000 VND、自動コメント用)、停電に耐えたい場合は **UPS**。詳細は [Day 0](/ja/a2-lo-trinh-mot-tuan/a3-ngay-0-chuan-bi)。

**wifi のノート PC で動かせますか?**
**GenRouter H3000** を使う場合は可能です。**mini PC** の場合は **LAN** 接続が必須 — Ethernet ポートのないノート PC には USB-to-LAN アダプタが必要です。[Day 0](/ja/a2-lo-trinh-mot-tuan/a3-ngay-0-chuan-bi) の「コントロール PC の接続方法」表を参照。
