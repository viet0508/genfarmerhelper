## 用意するもの: お金 · 時間 · 人

### お金 — box 以外に必要なすべて

購入した box とパッケージが**すべてではありません**。この表は残りの項目をまとめたもので、box が届く前に揃えておけば途中で止まりません。

| 項目 | 必須? | 費用 | 入手先 |
| --- | --- | --- | --- |
| **コントロール PC**(ノートまたはデスクトップ) | 必須 | 手持ちのもの | 手元 |
| **有線ネットワーク** + モデムの空きポート1つ | 必須 | 0 | 手元 |
| **専用の3ピンコンセント**、エアコンや洗濯機と共有しない | 必須 | なければ少額 | 電気店 |
| **SNS アカウント** — テスト用に5個、その後最大20個 | 必須 | 下の「記入待ち」ボックス参照 | サードパーティ — 信頼できる提供元を選ぶ |
| **プロキシ** — テスト用に5個、その後最大20個(電話1台に1つ) | 必須 | 下の「記入待ち」ボックス参照 | サードパーティ — 信頼できる提供元を選ぶ |
| **vilao.ai の API キー**(自動コメント用) | 自動コメントを使う場合のみ | 約50,000 VND(手数料約2%) | [vilao.ai/console](https://vilao.ai/console) |
| **UPS 1,000VA 以上** | 推奨 — 停電時のクラッシュを防ぐ | 下の「記入待ち」ボックス参照 | 電気店 |
| **Cat6 LAN ケーブル** | mini PC の場合のみ | 少額 | PC ショップ |
| **USB-to-LAN / Type-C-to-LAN アダプタ** | ノート PC に Ethernet ポートがない場合のみ | 約100,000〜200,000 VND | PC ショップ |
| **開封動画を撮る電話** | 必須 — 保証の証拠になる | 0 | 手元 |

:::tip[節約のコツ]
まず**アカウント5個 + プロキシ5個**だけ買ってテストしてください。うまく動いてから20個に拡大します。最初から20個買わないこと。

### 人 — 誰が何をするか

1人で全部できます。会社に2人いる場合は、次のように分担します:

* **経営者** — アカウント/プロキシの購入先を決め、プラットフォームと分野を選び(Day 4〜5)、下の*リスク*を読み、開封動画を保管する。
* **オペレーター** — 5日間のロードマップを進め、毎朝システムを確認し、詰まったらテンプレートでサポートに連絡する。

## 始める前に知っておくべきリスク

驚かないように率直に書きます。どのリスクにも軽減策があり、ドキュメントが該当箇所を示します。

* **アカウントが凍結されることがある** — 複数の電話が1つのプロキシを共有した時や、Day 2 の設定を誤った時に最も多い。*軽減:* 電話1台にプロキシ1つ、Day 2 を順番通りに、20に拡大する前に5でテスト。
* **最初の2〜4週間で数字が伸びないのは正常** — アカウントが「生きる」には時間が必要。*軽減:* 設定をいじり続けない;Day 4〜5 で正しい分野を選ぶ。
* **熱と電源** — 閉じた棚の中の box は自ら性能を落とす;大型家電とコンセントを共有すると実行中にシステムが落ちる。*軽減:* 風通しの良い場所、専用コンセント、UPS。
* **間違ったアプリのインストール** — 旧マニュアルのリンクは別のアプリにつながる。*軽減:* Day 2 の公式 APK フォルダのみ使う。
* **ハードウェア保証** — 開封動画がないと工場出荷時の不良を証明しにくい。*軽減:* **封を切る前に**撮影し、封をそのまま残す。
* **アカウントとプロキシはあなたの費用**で、サードパーティから購入 — 信頼できる提供元を選び、小さく始める。

:::caution[公開前に GenFarmer が記入する項目]
以下の数値は元資料にないため、創作していません。記入後、このボックスを削除してください。
* 推奨提供元での**アカウント**と**プロキシ**の参考価格
* 推奨 **UPS** の価格
* **サポートの営業時間**(現在「更新中」)
* **アカウント凍結時のポリシー**: 誰が費用を負担するか、代替の支援はあるか
* (任意)お客様がイメージできる **4週間後の典型的な結果**
:::

## 新規のお客様からよくある質問

**技術に詳しくないけど使えますか?**
使えます。5日間のロードマップは完全初心者向けに書かれています — 1日1つ、専門用語なし、必要な時のための [用語集](/ja/thuat-ngu) もあります。

**途中で詰まったら?**
まず [症状から検索](/ja/tra-cuu-theo-trieu-chung) を開いてください。それでもダメなら、テンプレートを使って [WhatsApp サポートにメッセージ](/ja/lien-he-ho-tro) — 5項目を送れば一度の返信で解決します。

**HDSD とは?**
機器に付属する141ページの完全版**ユーザーマニュアル**です。このサイトは*順番と理由*を教え、HDSD は詳細な参照資料です。「HDSD p.30」はそのマニュアルの30ページを開くという意味です。

**wifi のノート PC で動かせますか?**
**GenRouter H3000** を使う場合は可能です。**mini PC** の場合は **LAN** 接続が必須 — Ethernet ポートのないノート PC には USB-to-LAN アダプタが必要です。[Day 0](/ja/a2-lo-trinh-mot-tuan/a3-ngay-0-chuan-bi) の「コントロール PC の接続方法」表を参照。
