## 連絡する前の2分間セルフチェック

多くの場合は、すぐにご自身で解決できます。

| いま起きていること                | クイックチェック                                                                                                      |
| ------------------------ | ------------------------------------------------------------------------------------------------------------- |
| Scan を押しても端末が見つからない      | 2つのアドレス範囲を追加して **Active** を押しましたか？ → [A4 · 手順3](/ja/a2-lo-trinh-mot-tuan/a4-ngay-1-phan-cung)                     |
| 端末は表示されるがネットワークがない       | プロキシは生きていますか？端末の時刻は正しいですか？ → [A4 · 手順3](/ja/a2-lo-trinh-mot-tuan/a4-ngay-1-phan-cung)                             |
| 多数のアカウントが同時に凍結（BAN）された   | プロキシを共有しているアカウントはありませんか？ → [A5](/ja/a2-lo-trinh-mot-tuan/a5-ngay-2-danh-tinh)                                     |
| アプリをインストールしたら別のアプリが入っていた | ユーザーマニュアル（HDSD）内のリンクからダウンロードしていませんか？[A5 · 手順3](/ja/a2-lo-trinh-mot-tuan/a5-ngay-2-danh-tinh)の公式 APK フォルダーを使ってください |
| 数値が伸びない                  | 2〜4週間の育成は済んでいますか？分野は正しく選んでいますか？ → [A7](/ja/a2-lo-trinh-mot-tuan/a7-ngay-4-5-nen-tang)                             |

完全な一覧は[症状から探す](/ja/tra-cuu-theo-trieu-chung)を参照してください。

## 添えるべき5つの情報

1. 使用中の **Box の台数**と、**GenRouter H3000 とミニPCのどちら**を使っているか
2. 接続は **USB と OTG のどちら**か
3. ロードマップの**何日目**（0〜5日目）で、**どの手順**を行っているか
4. **Scan で何台見つかったか** / 何台が稼働中か
5. エラー発生時のソフトウェアの**スクリーンショット**（関連する場合はスマートフォンの画面も）

## メッセージのテンプレート — コピーして、記入して、送信

```
[GenFarmer サポート]
- Box の台数: ... (H3000 / ミニPC)
- 接続: USB / OTG
- 現在の位置: ...日目 – 手順...
- Scan の結果: ... / ... 台
- 問題: (何をしていて、画面に何が表示されているか)
- 試したこと: ...
- スクリーンショット: (添付)
```

:::note
上の5項目が揃ったメッセージは、何度もやり取りを繰り返すことなく、1回の返信で解決することがほとんどです。
:::

## ハードウェアの保証

製造上の不具合が疑われる場合は、[0日目](/ja/a2-lo-trinh-mot-tuan/a3-ngay-0-chuan-bi)に撮影した**開封ビデオ**を添えてください（シールはそのまま残しておきます）。これが保証の証拠になります。
