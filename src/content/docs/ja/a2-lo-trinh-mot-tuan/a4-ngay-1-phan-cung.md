**レイヤー1 · Boxphone**

> **今日の問い：** 端末は自分の指示に従うか？
>
> 1日目：GenFarmer Software アプリの基本操作を通じて、ソフトウェアの動き方を体感します。

<figure><img src="/images/11-a4-dan-boxphone.jpg" alt="GenFarmer boxphone の列" loading="lazy" /><figcaption>実際の boxphone の列。Day 1 の終わりには1台の PC からこれ全体を操作できます。</figcaption></figure>

**ソフトウェアのダウンロード → Box + ルーターのセットアップ → ソフトウェアの基本的な手動操作**

## 手順

### ソフトウェアをダウンロードする

[genfarmer.com/download](https://genfarmer.com/download/) から GenFarmer ソフトウェアをダウンロードし、インストールします。_ユーザーマニュアル（HDSD）p.1_

### ログインする

アバターのアイコンをクリックし、**Login** を選びます。アカウントがまだない場合は先に登録してください。_HDSD p.2–3_

### お持ちの機器に合わせて接続方法を選ぶ

ここで行き詰まる人が最も多いので、よく読んでください。

| お持ちの機器                       | モード           | 理由                                        |
| ---------------------------- | ------------- | ----------------------------------------- |
| **Box 1台 + GenRouter H3000** | **USB**       | H3000 が扱えるのは **Box 1台**まで。実際には2台を動かしきれません |
| **ミニPC**（Box が1〜2台でも）        | **OTG**       | 端末はミニPCのネットワークを使うため、既定で OTG になります         |
| **ミニPCも H3000 もない**          | OTG または Wi-Fi | 必要に応じて柔軟に選べます                             |

**USBモード — H3000**

接続するだけで自動的に認識されます。_HDSD p.8_

**OTGモード — ミニPC**

1. `192.168.4.1–255` と `192.168.5.1–255` の2つのアドレス範囲を追加します。
2. **Active** を押します。
3. **Scan** を押します。_HDSD p.4–7_

:::note
OTGモードでは、**端末はミニPC経由ですでにネットワークにつながっています**。
:::

**OTG を接続してもスマートフォンがネットワークにつながらない場合 — 次の順で確認します：**

1. **プロキシ** — プロキシが動作しているか。
2. プロキシに問題がなければ、**スマートフォンの時刻**を確認します。時刻がずれていれば修正します。お使いの PC の時刻に合わせて構いません。

:::note
HDSD には3つの配線図が並んで載っています。上の表に従って1つを選んでください。3つすべてを行う必要はありません。
:::

### 端末のシステム時刻を変更する

使用しているタイムゾーンに合わせます。お使いの PC の時刻に合わせて構いません。

### 任意の1台でフラッシュライトをオン／オフする

最も小さく、しかし最も分かりやすいテストです。端末が数秒以内に反応すれば、制御の経路はつながっています。

:::note
操作は [GenFarmer 操作説明ビデオのプレイリスト](https://www.youtube.com/watch?v=dWUFV9oCnL0\&list=PLDKj59ZxjjPzvYAxEBUXjYxkUAG624lBu\&index=10)で確認してください。この手順の個別ガイドは追加予定です。すぐに必要な場合は[サポートに連絡](/ja/lien-he-ho-tro)してください。
:::

### 操作の同期を試す

1台で操作して、20台すべてが同じ動きをするか確認します。

### 15分ほど、数台を手で操作して慣れる

時間の無駄に見えますが、そうではありません。[3日目](/ja/a2-lo-trinh-mot-tuan/a6-ngay-3-tu-dong)は、この感覚を土台にして進めます。

### 任意：adb コマンドをいくつか試す

技術的な知識がある方向けです。試さなくても問題ありません。

## 完了の目安

:::tip
**20台中20台**が画面に表示され、すべて Wi-Fi に接続でき、フラッシュライトを押すと端末が反応する。
:::

:::danger
満たしていなければここで止まり、**2日目に進まないでください**。次の情報を添えて[サポートに連絡](/ja/lien-he-ho-tro)してください：使用中の Box の台数、USB と OTG のどちらのモードか、Scan で何台見つかったか。
:::

## よくある3つの失敗

| ✕ | 失敗                              | 原因 / 対処                                                 |
| - | ------------------------------- | ------------------------------------------------------- |
| 1 | Scan を押しても端末が1台も見つからない          | ほとんどは、2つのアドレス範囲を追加していないか、追加したのに **Active** を押し忘れたのが原因です |
| 2 | OTG を接続してもスマートフォンがネットワークにつながらない | まずプロキシを確認します。プロキシに問題がなければ、スマートフォンの時刻を確認します              |
| 3 | H3000 で Box 2台を使う               | H3000 が扱えるのは Box 1台までです。Box 2台以上ではミニPCが必要で、OTG で接続します   |

:::note
操作用PCに **Wi-Fi は必須ではありません**。Wi-Fi をオフにして LAN で接続しても問題なく使えます（H3000 の場合もミニPCの場合も）。ミニPCでは Wi-Fi は使えません。
:::
